# Bosques de Zapan Etapa 3 — Portal de Propietarios

Prototipo comercial funcional, sin conexión todavía con SISCO.

## Cómo probarlo
1. Abra `index.html` en un navegador.
2. Propietario de demostración:
   - Documento: `1010101010`
   - Contraseña: `1234`
3. Administración:
   - Usuario: `admin`
   - Contraseña: `admin123`

## Incluye
- Login
- Portal de propietarios
- Estado de cuenta
- Mora y saldo
- Parqueaderos de carro y moto
- Historial de pagos
- Comunicados
- Panel administrativo
- Dashboard de cartera
- Consulta de propietarios
- Control de parqueaderos
- Datos ficticios para presentación
